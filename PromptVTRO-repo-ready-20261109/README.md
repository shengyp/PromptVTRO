# LLM课程学习 · 课程门户前端

基于 [EduTechLLM](https://github.com/shengyp/EduTechLLM) 现有前端扩展的大语言模型课程门户原型。项目目前提供**登录前课程门户**和 **LangChain 专题学习页**，保留原有绿色视觉风格，参考希冀平台公开课程页组织信息。

> **当前阶段：**门户与专题页面可本地演示；视频通过百度网盘查找和观看。真实账号、教学业务数据及模型问答需要连接完整后端，本前端包未包含后端、数据库或模型权重。

## 快速开始

克隆或下载本仓库，在包含 `package.json` 的仓库根目录运行。建议使用原项目采用的 Node.js 24 和 pnpm：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开终端显示的本地地址，通常为 [http://127.0.0.1:5173/?demo](http://127.0.0.1:5173/?demo)。如果 5173 已被占用，以终端显示的端口为准。从首页点击“进入专题”，或访问 `http://127.0.0.1:5173/?demo#langchain-topic` 查看 LangChain 页面。

`?demo` 是仅在 Vite 开发环境生效的前端演示模式，可选择学生、教师或管理员查看界面。它不进行真实账号认证；演示数据刷新后重置。

构建前端：

```sh
pnpm build
```

构建产物位于 `dist/`。依赖目录 `node_modules/` 和构建产物 `dist/` 已写入 `.gitignore`，不属于源码。

## 功能与资源

- **公开门户：**提供课程导览、开放课程、实训、比赛、OnlineJudge、综合实践、毕业设计和 GitLab 等栏目。未接入的服务以规划内容展示。
- **LangChain 专题：**根据分享中 day01、day02、day03 的 MP4 文件名整理为 5 个单元、48 条视频目录；页面展示课程介绍、学习路径、章节列表和资料入口。
- **视频观看：**视频文件不在本仓库。点击章节条目可查看网盘文件路径；打开分享后需手动找到对应视频。下载视频后，也可在专题页选择本机文件夹，匹配到的 MP4 会在浏览器中播放，文件不会上传到本站。课程笔记和环境资料可从网盘入口查找。
- **角色界面：**教师端包含课程互动题、题库、试卷、作业、教学设计、知识图谱和班级管理入口；学生端包含课程选择、自主练习等入口；管理端包含教师审核、权限和班级管理入口。这些界面的实际数据和权限控制需要后端支持。

## 与完整项目的关系

本仓库当前提供可直接浏览的前端源码。原项目的 Node.js／Java 后端、MySQL 数据库、Ollama 服务及其配置均不在此仓库中。`vite.config.js` 将前端的 `/api/` 请求默认代理到 `http://127.0.0.1:3002`；连接原项目 Node 后端时，可通过 `EDUTECH_API_TARGET` 指定实际地址。

`package.json` 保留原项目的 `server`、`db:migrate` 和 `test:backend` 脚本，但本仓库没有 `server/` 目录，不能单独运行这些脚本。真实登录、会话保存、模型问答和教学业务功能应在完整项目环境中验证。

## 验证与后续建设

已验证前端生产构建，以及专题导航、章节展开、网盘路径弹窗和手机端布局。本机视频播放功能已接入页面，但尚未用你的实际视频文件逐节验收。平台托管视频、章节习题、学习进度统计及真实后端接口仍待建设。

部署正式环境时，需要为静态页面配置 `/api/` 转发并连接对应后端；本版本尚未验证公网部署。不要将 `.env`、账号密码、模型密钥、数据库备份或模型权重上传到公开仓库。
