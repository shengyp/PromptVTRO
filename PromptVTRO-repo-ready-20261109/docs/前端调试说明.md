# 前端本地调试

在仓库根目录（包含 `package.json`）打开 PowerShell，首次运行先执行：

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

开发服务器默认地址为 `http://127.0.0.1:5173/`。若该端口已占用，以终端显示的新端口为准。

## 公开课程门户

打开开发服务器首页即可查看登录前的 LLM 课程门户。页面沿用原前端深绿色视觉，加入开放课程、实训、比赛、OnlineJudge、综合实践、毕业设计、GitLab 和教师登录栏目，以及公告、在线服务和课程展示区。顶部导航会跳转到对应区块。

没有后端时，公开内容仍可浏览；登录表单会显示连接提示并暂时禁用。课程路线与实训内容标注为规划示意，赛事、在线评测和代码托管没有伪装成已上线功能。

## LangChain 专题视频

公开门户的“开放课程”上方有“LangChain 大模型应用开发”专题入口，也可直接打开 `http://127.0.0.1:5173/?demo#langchain-topic`。若终端显示的是 5174 等其他端口，请相应替换。点击入口进入参考希冀课程详情页布局的专题页面，查看课程介绍、五步学习路径、相关资料和章节目录。专题目录按用户提供的百度网盘分享整理了三天目录中直接列出的 48 个 MP4，分成五个学习单元；原有 16 门规划课程保持独立。授课团队、正式开课时间和学生学习数据未核实，不展示虚构信息。

点击一个视频小节可查看原文件路径和“前往百度网盘观看”入口。分享链接打开的是网盘文件列表，暂不能自动定位到该视频；需按路径找到文件，网盘也可能要求登录。专题页还提供本机文件夹选择和浏览器播放器：下载视频后可在本机匹配并播放，文件不会上传到本站。课程笔记和环境资料在网盘中提供查找入口；章节练习尚未接入。

## 无后端演示

在开发服务器中打开以下地址，可以直接查看各角色工作台：

- 学生端：`http://127.0.0.1:5173/?demo=student`
- 教师端：`http://127.0.0.1:5173/?demo=teacher`
- 管理端：`http://127.0.0.1:5173/?demo=admin`
- 公开门户及演示角色选择：`http://127.0.0.1:5173/?demo`

演示模式只在 Vite 开发服务器中启用。示例数据仅保存在当前页面内存中，刷新后重置；问答内容是明确标注的界面占位回复，不调用后端或模型。未模拟的接口会返回明确提示。

## 后续连接后端

去掉 URL 中的 `?demo` 即使用真实接口。Vite 默认代理到 `http://127.0.0.1:3002`。需要连接 Node 后端时，在启动前设置：

```powershell
$env:EDUTECH_API_TARGET = 'http://127.0.0.1:3001'
pnpm dev
```

修改代理地址后需要重启开发服务器。`pnpm build` 会在仓库根目录生成 `dist/`，生产版不会启用演示接口。

本仓库按前端源码组织，`src/` 保存页面代码，`public/` 保存静态资源。`dist/` 由 `pnpm build` 生成，不纳入源码仓库；早期交付快照和清单保存在原始交付文件夹中。
