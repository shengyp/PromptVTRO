# LLM课程学习 · 课程门户前端

大语言模型课程门户前端原型，保留原项目的绿色视觉风格。第三版将 LangChain 学习内容纳入开放课程列表，并增加站内视频演示、可展开的思维导图、章节练习、期末考试和个性化学习示例。

## 查看源码

前端源码与完整功能说明在 [PromptVTRO-repo-ready-20261109](./PromptVTRO-repo-ready-20261109/README.md)。仓库根目录不再放重复的源码压缩包。

## 本地运行

需要 Node.js 24 和 pnpm。在仓库根目录打开 PowerShell，依次输入：

    cd .\PromptVTRO-repo-ready-20261109
    pnpm install --frozen-lockfile
    pnpm dev

打开终端显示的地址，通常是 http://127.0.0.1:5173/?demo。进入“开放课程”，点击第一张 LangChain 课程卡片。地址中的 ?demo 仅用于开发环境的前端演示，不是真实账号登录。

## 当前阶段

课程目录有 5 个单元、48 个视频文件名。仓库仅包含 1 段自制播放器演示视频；原课程视频、真实成绩、后端讨论和智能助手尚未接入。练习与考试是自编演示题，未经教师审核。

请勿提交环境配置、账号密钥、数据库备份、模型权重或未获授权的课程原视频。详细的运行和资源说明见子目录 [README](./PromptVTRO-repo-ready-20261109/README.md)。
